# ClonalG: Clonal Selection Algorithm for Data Clustering

An implementation of the Clonal Selection Algorithm (CLONALG) adapted for unsupervised data clustering and dynamic centroid optimization, developed in the context of Natural Computing and Artificial Immune Systems (AIS).

---

## Overview

The Clonal Selection Algorithm (CLONALG), originally proposed by de Castro and Von Zuben, is an evolutionary heuristic inspired by the clonal selection theory of the acquired immune system. 

This project adapts the immunological principles of affinity maturation, somatic hypermutation, and receptor editing to the problem of partitional data clustering. Rather than requiring a strictly fixed number of clusters $k$, the algorithm evaluates candidate antibody centroids and can dynamically adjust the cluster count between $[k_{min}, k_{max}]$ using the Silhouette Coefficient as an unsupervised affinity metric.

---

## Key Features

- **Antibody Representation**: Each antibody represents a candidate set of $k$ centroids selected from the feature space, with $k \in [k_{min}, k_{max}]$.
- **Affinity Metric**: Evaluation via the Silhouette Coefficient to quantify cluster cohesion and separation without requiring labeled ground truth.
- **Proportional Cloning**: The number of clones generated by an antibody is directly proportional to its affinity:
  $$N_{clones} = \lfloor \beta \cdot f^* \rfloor + 1$$
- **Inversely Proportional Hypermutation**: The mutation rate $\alpha$ decreases exponentially as affinity increases:
  $$\alpha = e^{-\rho \cdot f^*}$$
  Mutations include geometric centroid perturbation as well as structural mutations (adding or removing centroids).
- **Memory Pool**: High-affinity solutions are stored and refined across generations to prevent catastrophic forgetting.
- **Receptor Editing**: A percentage of the lowest-affinity antibodies are replaced by new random candidates in each iteration to maintain population diversity and escape local optima.
- **Comparative Benchmarking**: Direct experimental comparison against classical K-Means across multiple synthetic and real-world datasets.

## Usage

### 1. Data Preprocessing

Prepares the datasets by imputing missing values, applying standard scaling (`StandardScaler`), and generating preliminary PCA projections:

```bash
python preprocessamento.py
```

Cleaned datasets will be saved with the suffix `_scaled.csv` inside the `datasets/` directory.

### 2. Parameter Tuning

Runs iterative experiments over hyperparameter combinations ($\beta$, $\rho$, replacement rate, memory rate, and antibody count):

```bash
python experimentos_parametros.py
```

Outputs the best configurations found per dataset to `resultados/etapa3_parametros/melhores_configuracoes.csv`.

### 3. Final Comparative Analysis (ClonalG vs. K-Means)

Executes multiple statistical runs comparing ClonalG against standard K-Means using the Silhouette metric, PCA cluster visualizations, and convergence tracking:

```bash
python comparativo_final.py
```

Comparative charts and summary tables are generated inside `resultados/comparativo_final/`.

## Programmatic API

You can also use the `ClonalG` class directly inside your Python scripts:

```python
import numpy as np
from clonalg_core import ClonalG

# Generate or load your scaled data
X = np.random.randn(150, 4)

# Instantiate the algorithm
model = ClonalG(
    n_antibodies=20,
    k=3,
    k_min=2,
    k_max=6,
    rho=2.5,
    beta=15,
    replace_rate=0.2,
    selection_rate=0.8,
    memory_rate=0.25
)

# Fit to data
best_centroids, affinity_history = model.fit(X, n_iterations=30, verbose=True)

# Predict cluster labels for samples
labels = model.predict(X, best_centroids)
```

## Hyperparameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `n_antibodies` | `int` | `10` | Population size (total number of candidate solutions) |
| `k` | `int` | `3` | Initial number of cluster centroids |
| `k_min` | `int` | `2` | Minimum allowable number of clusters |
| `k_max` | `int` | `6` | Maximum allowable number of clusters |
| `beta` | `float` | `10.0` | Scaling factor controlling clone expansion |
| `rho` | `float` | `2.0` | Hypermutation decay rate |
| `replace_rate` | `float` | `0.10` | Fraction of population replaced by random candidates |
| `selection_rate` | `float` | `1.0` | Proportion of memory antibodies selected for cloning |
| `memory_rate` | `float` | `0.25` | Proportion of top antibodies preserved in memory |
